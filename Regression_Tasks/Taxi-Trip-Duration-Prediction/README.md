# <center> **PROJECT: Taxi Trip Duration Prediction**

Regression model for predicting the duration of taxi rides based on trip characteristics.

---

### **Project Goal**

Build an accurate machine learning model to predict how long a taxi trip will take (in minutes). This helps taxi services optimize routing, improve customer experience, and better plan driver workload.

---

### **Business Problem**

Taxi companies need reliable trip duration predictions to provide accurate ETAs to customers, optimize dispatch systems, and improve operational efficiency.

---

### **Dataset**

- **Task type**: Regression (predicting trip duration)
- **Key Features**:
  - Pickup and dropoff locations
  - Distance and route information
  - Time of day and day of week
  - Weather conditions
  - Traffic information
  - Passenger count and other trip metadata

---

### **Technologies Used**

- `pandas`, `numpy`
- `scikit-learn` (Linear Models, Tree-based, Ensemble)
- `XGBoost`
- `matplotlib`, `seaborn`, `plotly`
- `scipy` (statistical analysis)
- Feature Engineering & Selection

---

### **Project Stages**

1. Exploratory Data Analysis (EDA)
2. Data cleaning and preprocessing
3. Feature Engineering (creating new meaningful features)
4. Statistical analysis and outlier detection
5. Model training and comparison (Linear Regression, Decision Trees, Random Forest, XGBoost, etc.)
6. Hyperparameter tuning
7. Building a prediction pipeline for new data
8. Final evaluation and conclusions

---

### **Key Achievements**

- Performed extensive Feature Engineering tailored for trip duration prediction
- Successfully handled spatio-temporal data
- Built and compared multiple regression models
- Developed a complete end-to-end prediction process for new trips

---

### **Conclusion**

This project demonstrates strong skills in solving real-world regression problems with spatio-temporal data. The developed model allows accurate prediction of taxi trip duration, which can be used in production systems to improve service quality and operational efficiency.
