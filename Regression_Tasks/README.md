# <center> **Regression Tasks**

This folder contains various **regression projects** focused on predicting continuous numerical values using classical machine learning approaches.

---

### 📁 Projects

- **[Energy Consumption Prediction](Energy-Consumption-Prediction/)**  
  Forecasting energy consumption (GW·h) based on sustainable energy data from 2000–2020, including renewable production, GDP, population, and CO₂ emissions.

- **[Hotel Rating Prediction](Hotel-Rating-Prediction/)**  
  Regression model to predict hotel ratings and detect potential review manipulation or unfair practices.

- **[House Price Prediction](House-Price-Prediction/)**  
  Predicting real estate prices based on property characteristics (area, number of rooms, location, year built, etc.).

- **[Taxi Trip Duration Prediction](Taxi-Trip-Duration-Prediction/)**  
  Predicting the duration of taxi trips in minutes using features such as distance, time of day, traffic, and weather conditions.

- **[Tutors Lessons Prices Prediction](Tutors-Lessons-Prices-Prediction/)**  
  Predicting the average price per minute of private tutoring lessons based on tutor experience, qualifications, subject, rating, and location.

- **[Bayesian vs Classical Linear Regression](Bayesian-vs-Classical-Linear-Regression/)**  
  Apartment price prediction (Sberbank Housing Market) with comparison of classical linear regression (`scikit-learn`) and Bayesian linear regression (`PyMC`). Includes coefficient analysis and credible intervals.
