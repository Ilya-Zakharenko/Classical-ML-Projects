# <center> **REGRESSION TASKS PROJECTS.**


This folder contains a collection of projects focused on **regression tasks**, a type of supervised machine learning where the goal is to predict continuous numerical values. These projects showcase various regression techniques, such as linear regression, polynomial regression, bayesian methods, uplift-modeling and more, applied to real-world datasets.

---

### **Projects**

- **[Bayesian vs Classical Linear Regression - Apartment Price Prediction](Bayesian_vs_Classical_Apartment_Price_Prediction/)**  
  Comparison of classical linear regression (`scikit-learn`) and Bayesian linear regression (`PyMC`) on the Sberbank Housing Market dataset.  
  Special focus on coefficient interpretation, uncertainty estimation using Highest Density Intervals (HDI), and the effect of log-transforming the target variable.
