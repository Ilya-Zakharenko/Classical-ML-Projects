# <center> **PROJECT: ShopTalkBot**  
Conversational Product Recommender & Chit-Chat Bot

Этот проект представляет собой гибридный чат-бот «барахольщик»: по продуктовому запросу он рекомендует товары, по всем остальным запросам ведёт непринуждённую болтовню (без фолбека / заглушки «не понял»).

---

### **Description**

**ShopTalkBot** — это демонстрационный чат-бот, который сочетает два режима работы в одном диалоге:

- **Продуктовый режим** — поиск и рекомендация похожих товаров на основе векторного поиска (content-based filtering)
- **Болталка** — лёгкий разговор на любые темы, не связанные с покупками

Проект показывает end-to-end пайплайн классического NLP без использования нейронных сетей и больших языковых моделей.

---

### **Main Goals**

- Собрать и подготовить набор данных из открытых источников
- Выполнить Feature Engineering и отобрать наиболее значимые признаки
- Провести качественную векторизацию текстовых описаний
- Обучить / настроить модель поиска похожих товаров
- Реализовать логику распознавания продуктового запроса
- Создать естественную «болталку» на нерелевантные темы
- Объединить оба режима в единую диалоговую логику

---

### **Project Stages / Structure**

Проект разбит на логические части (каждая часть — это отдельный ноутбук или скрипт):

1. **Базовый анализ и знакомство с данными**  
2. **Предобработка и очистка данных**  
3. **Feature Engineering (создание новых признаков)**  
4. **Векторизация текста**  
5. **Machine Learning (обучение модели поиска похожих товаров)**  
6. **Реализация поиска похожих товаров (content-based часть бота)**  
7. **Реализация болталки (fallback / chit-chat логика)**  
8. **Выводы и демонстрация работы бота**

---

### **Used Tools & Libraries**

- `Python`
- `Pandas`, `NumPy` — обработка данных
- `scikit-learn` — TF-IDF, cosine similarity, классификаторы
- `NLTK` / `spaCy` / `pymorphy2` — токенизация, лемматизация (особенно для русского языка)
- `matplotlib`, `seaborn` — визуализация распределений и результатов поиска
- `jupyter` — эксперименты и отладка
