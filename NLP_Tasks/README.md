# <center> **NLP Tasks**  
Natural Language Processing Projects

This folder contains a collection of projects related to **Natural Language Processing (NLP)** — the field of AI focused on understanding, processing, and generating human language.

The projects demonstrate both classical (non-deep learning) and (potentially in the future) modern approaches to text-related tasks.

---

### **Description**

All projects in this category involve working with text data: classification, information retrieval, dialogue systems, feature extraction from unstructured text, etc.

Current projects include rule-based systems, traditional machine learning models (TF-IDF + classifiers), text vectorization techniques, and simple conversational agents.

This collection is part of a broader classical ML portfolio and aims to show practical skills in text processing without relying on large pre-trained transformers / LLMs.

---

### **Projects**

- **[ShopTalkBot](ShopTalkBot/)**  
  A hybrid conversational recommender chatbot ("барахольщик") that recommends products on shopping-related queries and engages in casual chit-chat on other topics.


---

### **Common Tools & Libraries**

- `Python`
- `Pandas`, `NumPy` — data handling
- `scikit-learn` — vectorization (TF-IDF, CountVectorizer), classification (Logistic Regression, etc.)
- `NLTK`, `spaCy`, `pymorphy2` / `natasha` — tokenization, lemmatization, basic linguistic processing
- `matplotlib`, `seaborn` — visualization of results

Each project has its own `requirements.txt` file.
