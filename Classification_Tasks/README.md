# <center> **Classification Tasks**

This folder contains various **classification projects** using classical machine learning algorithms. 

Here I explore different real-world binary and multiclass classification problems, from customer behavior to environmental prediction.

---

### 📁 Projects

- **[Airline Passenger Satisfaction Prediction](Airline-Passenger-Satisfaction-Prediction/)**  
  Binary classification to predict whether a passenger is satisfied with the flight based on survey data.

- **[Bank Deposit Marketing](Bank-Deposit-Marketing/)**  
  Binary classification to identify clients most likely to open a term deposit for targeted marketing campaigns.

- **[Gender Classification by Voice](Gender-Classification-by-Voice/)**  
  Binary classification to determine gender based on acoustic voice features.

- **[Oil and Gas Fields Classification](Oil-and-Gas-Fields-Classification/)**  
  Classification of oil and gas fields using geological and geophysical data.

- **[Rain Prediction in Australia](Rain-Prediction-in-Australia/)**  
  Binary classification to predict whether it will rain tomorrow based on meteorological data.

### 🛠 Technologies & Approaches

**Core Libraries**
- `pandas`, `numpy`
- `scikit-learn`
- `XGBoost`, `CatBoost`, `LightGBM` (in some projects)
- `matplotlib`, `seaborn`, `plotly`

**Models Used**
- Logistic Regression
- Random Forest
- Gradient Boosting (XGBoost, CatBoost)
- AdaBoost
- Ensemble methods

**Techniques**
- Feature Engineering
- Hyperparameter tuning (`GridSearchCV`)
- Class imbalance handling
- Model evaluation (Accuracy, Precision, Recall, F1, ROC-AUC)
